# Мои дела — версия для компьютера

Личный список дел и заметок. Сайт без сервера: страница в браузере сама читает и пишет
файл в папке приложения на Яндекс Диске владельца (доступ только к этой папке).
Тот же файл синхронизирует Android-приложение «Мои дела».

Данных пользователя в этом репозитории нет — только код страницы.

- `sync.js` — правила слияния изменений (проверка: `node sync.test.js`)
- `config.js` — ID приложения Яндекса и адрес сайта
